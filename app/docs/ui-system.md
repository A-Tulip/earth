# UI 系统

## 1. 设计原则

**AI Canvas 而非教育 Dashboard。** 地球和地貌是核心画布，UI 容器数量极少，通过留白、排版、空间标注和动效建立层级。

### 反模式（不出现）
- 课程时间轴、章节侧栏、聊天面板、机器人头像
- 课程缩略图墙、登录头像、永久底栏
- 霓虹描边、紫蓝渐变、大面积玻璃卡片、强发光、emoji、科幻机器人
- 左侧超长控制栏、多个弹窗、功能耦合（旧版问题）

### 正模式
- 中央完全交给数字地球
- 短信息贴合地貌显示
- 上下文操作离开对象后收起
- 一次只突出一个主要解释层

## 2. 视觉语言

- **方向**：自然科学、地图编辑、现代工具软件
- **强调色**：唯一克制的地理蓝青色（`geo-500: #0ea5e9`）
- **背景**：宇宙阶段深色（`ink-900: #0a0f1a`），区域地表按卫星影像自然调整
- **图标**：统一线性 SVG（`src/ui/icons.tsx`），无 emoji
- **字体**：Noto Sans SC，稳定字重，适合教室投屏的字号

## 3. 长期可见元素（极少）

| 位置 | 内容 |
|---|---|
| 左上 | 产品名"地球探索者"，进入课程后旁显当前主题 |
| 右上 | 课程入口、声音状态、全屏 |
| 中央 | 完整数字地球 |
| 左下 | 可折叠工具坞 |

**首次打开：** 显示完整地球 + 一句轻引导"按住空格说出你想观察的地点或知识点"，数秒后淡出（`Guidance.tsx`）。

## 4. 临时元素（按上下文短暂出现）

- 语音状态（"正在聆听"、识别结果、执行状态）
- AI 反馈
- 问题
- 知识解释
- 时间控件（仅时序课程）

完成后自动淡出。

## 5. 工具坞（`ToolDock.tsx`）

左下角，默认显示"视图、标注、天文、数据、测量"5 个紧凑入口，可整体折叠成一个按钮。

- 点击入口 → 附近展开轻量菜单
- 点击地图空白处或按 Esc → 自动收起

### 工具坞分组

| 分组 | 承接能力 |
|---|---|
| 视图 | 卫星影像、地形模式、政区底图、二维、三维、恢复视角 |
| 标注 | 经纬线、城市、地名、气候带、板块、日界线、河流、山脉、行政边界 |
| 天文 | 地轴、太阳直射点、晨昏线、日间模式、自转、公转、速度 |
| 数据 | 天气、地震、自然事件、GDP、人口、温度、降水、卫星时序 |
| 测量 | 距离、面积、角度、高度、海拔、地形剖面、清除 |

## 6. 知识表达层级

| 信息长度 | 承载方式 | 高度 |
|---|---|---|
| 短信息 | 贴合地貌显示（如"青藏高原，平均海拔 4000 米以上"） | 单行 |
| AI 讲解 | 底部字幕 | 1-2 行 |
| 较长解释 | 底部向上展开的讲义层 | 屏幕 1/4，地图仍可见 |

讲义层操作：在地图上标出、换一种说法、生成问题、收起。**一次只突出一个主要解释层。**

## 7. 上下文操作

点击山脉/河流/城市/等高线/气团/板块/标注时，在点击位置附近显示对象相关操作：

| 对象 | 上下文操作 |
|---|---|
| 山脉 | 解释、聚焦、剖面、测量 |
| 河流 | 流向、流域、剖面、讲解 |
| 冷锋 | 暂停、剖面、降水、解释 |

离开当前对象后收起，**不形成固定右侧栏**。

## 8. 时间控件

**全局不设置课程时间轴。** 时间控制器只在课程内容本身具有时间变化时出现：
- 地球自转、公转、晨昏线
- 台风移动、锋面移动、季风变化
- 卫星影像对比、人口迁移、城市化

普通区域地理、等高线、地势分布、板块边界、地貌识别**不显示时间控件**。临时控件在相关场景结束后自动消失。

## 9. 课程命令菜单（`CommandMenu.tsx`）

点击右上角"课程" → 可搜索层级菜单：
- 先按初中/高中分类
- 再按自然地理/人文地理/区域地理/地球地图分类

选中后菜单立即收起，地球进入对应场景。也可语音跳过菜单："开始八年级等高线课程"。

## 10. 配色与动效

### Tailwind 主题（`tailwind.config.js`）

```js
geo: { 500: '#0ea5e9', ... }  // 唯一强调色
ink: { 900: '#0a0f1a', ... }  // 深色背景
```

### 动效

- `fade-in` / `fade-out` / `slide-up` / `pulse-soft`
- 重点放在：镜头飞行、地形抬升、图层渐变、标注出现、剖面展开、AI 操作反馈

## 11. 响应式适配

| 设备 | 主交互 | 布局 |
|---|---|---|
| 桌面 | 空格 Push-to-Talk + 鼠标 | 全屏地球 + 左下工具坞 |
| 平板 | 触摸 + 麦克风按钮 | 同上，触控目标增大 |
| 手机 | 底部工具抽屉 + 竖屏 | 底部抽屉替代工具坞 |

全屏课堂模式自动降低工具透明度，仅保留必要内容。
