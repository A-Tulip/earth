# 地球探索者 - 项目介绍与功能说明

## 项目简介

**地球探索者**是一款基于 Web 的交互式 3D 地理教学平台，利用 Three.js 技术构建了一个可旋转、可交互的虚拟地球。项目面向中学和大学地理教学场景，提供直观的地球运动演示、地理数据可视化、AI 辅助学习等功能，帮助学生理解抽象的地理概念。

### 技术栈
- **3D 渲染引擎**：Three.js v0.160.0
- **前端技术**：HTML5 + CSS3 + JavaScript (ES6 Modules)
- **数据存储**：localStorage（本地持久化）
- **AI 集成**：支持火山引擎（豆包）/ OpenAI / Azure / 阿里云
- **语音识别**：Web Speech API
- **语音合成**：SpeechSynthesis API

## 功能说明

### 1. 3D 地球渲染系统

**核心文件**：`src/earth.html`

通过 Three.js 创建一个直径为 1 单位的高精度球体（64x64 分段），支持多种地图图层切换：

| 图层 | 说明 |
|------|------|
| 世界政区图 | 显示各国边界和行政区划 |
| 世界地形图 | 显示海拔和地形起伏 |
| 世界彩色图 | 彩色渲染的世界地图 |

- **图层切换**：快捷键 `1/2/3` 或控制面板切换
- **纹理加载**：使用 `THREE.TextureLoader` 加载本地图片资源
- **默认材质**：加载失败时自动回退到蓝色默认材质，保证应用不崩溃

### 2. 地球运动模拟

#### 2.1 自转
- 地球绕地轴自西向东旋转
- 速度可通过滑块调节（0.1x ~ 5x）
- 快捷键 `R` 切换自转开关
- 地轴倾斜角 23.5°（真实模拟）

#### 2.2 公转
- 模拟地球绕太阳公转运动
- 快捷键 `O` 切换公转开关
- 公转时同步更新太阳直射点位置

#### 2.3 太阳直射点
- 滑块调节太阳直射纬度（-23.5° ~ 23.5°）
- 实时显示太阳直射点位置标记
- 与公转联动，模拟四季变化

### 3. 经纬网系统

- 每 15° 绘制一条经线和纬线
- 重要纬线特殊标注：赤道（红色）、南北回归线、南北极圈
- 经纬度标签随相机距离自动缩放
- 快捷键 `G` 切换显示/隐藏

### 4. 晨昏线与昼夜系统

- 使用自定义 ShaderMaterial 渲染晨昏线
- 晨昏线将地球分为昼半球和夜半球
- 随太阳直射点位置实时更新
- 支持"白天模式"（全亮）和"昼夜模式"切换
- 快捷键 `T` 切换晨昏线显示

### 5. 国际日期变更线

- 沿 180° 经线绘制日期变更线
- 可切换显示/隐藏
- 快捷键 `D` 切换

### 6. 气候带划分

- 显示四个气候带：热带（红）、亚热带（黄）、温带（绿）、寒带（蓝）
- 包含极昼极夜区域显示
- 随太阳直射点位置动态更新
- 快捷键 `Z` 切换显示

### 7. 城市标记系统

- 内置全球主要城市数据（北京、上海、东京、纽约、伦敦、巴黎等）
- 城市标记显示在地球表面
- 鼠标悬停显示城市名称悬浮提示
- 点击城市弹出详细信息面板，包括：
  - 城市名称和所属国家
  - 实时本地时间（根据经度计算时区）
  - 天气信息（模拟数据）
  - 经纬度坐标
  - 日出日落时间
  - 飞行到该城市的动画
- 快捷键 `C` 切换城市标记

### 8. 洋流与季风动画

#### 8.1 洋流系统
- 显示全球主要洋流路径（暖流红色、寒流蓝色）
- 洋流沿路径流动动画
- 可切换显示/隐藏

#### 8.2 季风系统
- 显示季风方向和路径
- 动态风向箭头动画
- 可切换显示/隐藏

### 9. 测量工具

支持三种测量模式，测量标记和连线随地球自转同步旋转：

#### 9.1 距离测量
- 点击地球表面两个或多个点
- 显示各段距离和总距离（公里）
- 使用大圆距离公式计算

#### 9.2 面积测量
- 点击三个或更多点形成封闭区域
- 使用球面多边形面积公式计算（平方公里）

#### 9.3 角度测量
- 点击三个点形成角度
- 显示角度值（度数）

**测量特性**：
- 实时坐标显示（鼠标悬停时显示当前经纬度）
- 标记可拖拽调整位置
- 支持撤销上一步操作
- ESC 键退出测量模式
- 测量标记随地球自转保持位置（标记作为 earthGroup 子对象）

### 10. 大洲信息系统

- 七大洲 clickable 区域划分
- 点击大洲弹出详细信息面板：
  - 大洲概况（面积、人口、国家数）
  - 地形图（Canvas 手绘风格）
  - 主要国家列表
  - 主要城市列表
  - 地形与气候描述
  - 地理特征列表
- 地图支持缩放和拖拽预览
- "飞行到大洲"动画

### 11. 图集系统

- 内置世界地图图集（政区图、地形图、时区图等）
- 支持用户上传自定义图片
- 图片数据通过 localStorage 持久化存储
- 支持"恢复默认图集"功能
- 图片全屏查看（支持缩放、拖拽）
- 图集数据版本管理（防止旧数据损坏）

### 12. AI 智能助手

#### 12.1 本地知识库
- 内置地理知识问答库（地球、自转、公转、四季、时区等）
- 关键词匹配，快速回答常见地理问题

#### 12.2 云端 AI 集成
- 支持火山引擎（豆包）模型
- 支持 OpenAI GPT 系列模型
- 支持 Azure OpenAI
- 支持阿里云通义千问
- 可配置 API Key、模型名称、Endpoint ID
- 支持"本地回退"模式（云端失败时使用本地知识库）

#### 12.3 语音识别
- 支持中文语音输入（zh-CN）
- 实时语音转文字
- 自动重试机制（最多 3 次）
- 支持语音指令操作（打开面板、切换图层等）

#### 12.4 语音合成
- AI 回答支持语音朗读
- 可随时停止朗读

### 13. 学习助手系统

#### 13.1 知识学习
- 分类知识库（地球运动、气候环境、经纬坐标、地图知识）
- 每个分类包含多个知识点
- 支持关键词搜索

#### 13.2 知识问答
- AI 自动生成选择题
- 四个选项，即时判断对错
- 详细解释说明
- 答题进度追踪（总题数、正确率）
- 进度数据持久化存储

#### 13.3 经纬度练习
- 随机生成目标经纬度
- 用户在地球上点击对应位置
- 判断误差并给出评分

### 14. 世界时钟

- 显示全球主要城市的实时本地时间
- 根据城市经度自动计算时区偏移
- 每秒自动更新

### 15. 对比模式

- 支持两个场景的对比查看
- 可分别设置不同的参数（太阳直射点、自转速度等）

### 16. 场景分享

- 将当前场景状态（太阳高度、自转速度、图层开关等）编码为 URL 参数
- 通过 URL 分享特定场景
- 打开分享链接时自动还原场景

### 17. 性能优化模块

**文件**：`src/earth-optimization.js`

- **FPS 计数器**：实时显示帧率
- **内存监控**：显示内存使用情况
- **资源管理**：预加载和缓存纹理资源
- **响应式布局**：自适应不同屏幕尺寸
- **主题管理**：支持暗色/亮色主题切换

### 18. 快捷键系统

| 按键 | 功能 |
|------|------|
| `R` | 切换自转 |
| `O` | 切换公转 |
| `G` | 切换经纬线 |
| `A` | 切换地轴 |
| `T` | 切换晨昏线 |
| `C` | 切换城市标记 |
| `F` | 全屏模式 |
| `ESC` | 关闭弹窗/退出测量 |
| `+/-` | 调节自转速度 |
| `0` | 重置视角 |
| `1/2/3` | 切换地图图层 |

### 19. 用户设置

- 主题切换（暗色/亮色）
- 自动旋转开关
- 经纬线显示开关
- 地轴显示开关
- 晨昏线显示开关
- 性能统计（FPS、内存、资源加载）
- 数据管理（重置学习进度、清除缓存）

### 20. 欢迎引导

- 首次访问显示功能引导弹窗
- 可勾选"不再显示"跳过引导
- 引导内容涵盖核心功能介绍

## 启动方式

```bash

# 启动本地服务器（Python）

# 打开浏览器访问
# http://localhost:8081/src/earth.html
```
